# Proof modules

This catalogue describes the roles of the compiled modules. The public theorem
is `QuantumOracle.soundness : QuantumOracle.SoundnessStatement`; the original
`ImprovedSoundness.soundness` remains available. See [the statement guide](THEOREM_STATEMENT.md).

`Model/` holds the actual definitions and foundational proofs. `Statement/`
imports only that model and defines the final proposition. `Proof/` supplies
the main soundness argument. `Model/SoundnessPurification.lean` constructs the
actual pair; `Proof/FiniteSoundnessWitness.lean` proves its numerical bound.
`Proof/OutputComparison.lean` contains the local-error-to-output comparison.
Import boundaries are automatically checked.

| `Proof/Conditioning.lean`, `Proof/ConditioningQuery.lean` | The actual residual polar map and edge insertion construct J as an isometry whose image records the queried input. | `Proof/ConditioningError.lean` | The actual J-versus-pC-W discrepancy squared is the sum of its workspace-slice discrepancies squared. | `Proof/ConditioningSpectrum.lean` | Under actual full degree u+1, residual degree u for every answer, positive full/residual Gram eigenvalues gh,gr, and the same gr across all answers, definedPart(candidate h) equals c J h for c=sqrt(gr)/sqrt(gh), the actual overlap is c‖h‖², and ‖pC(candidate h)−J h‖²=2(1−c)‖h‖². For nonzero h, 0<c≤1 and gr≤gh follow. The eigenvector equations are explicit hypotheses, not Specht identification. |
| `Proof/ConditioningFirstRow.lean` | When the full input and every actual residual restriction have the same degree t and positive actual Gram eigenvalues gh,gr, with a common gr across answers, the defined component of candidate h vanishes and the actual overlap is (sqrt(gh)/sqrt(gr))‖h‖². The coefficient proof uses actual extension-state resolution; no overlap identity or Specht identification is assumed. |
| `Proof/ConditioningFirstRowBounds.lean` | Under those same actual degree/eigenvector hypotheses, the squared discrepancy is 2(1−sqrt(gh)/sqrt(gr))‖h‖². For nonzero h, the ratio lies in (0,1] and gh≤gr follows. The required quantitative estimate is supplied later by `ConditioningHookBounds`. |
| `Proof/EmbeddedExecution.lean` | The actual exact prefix embedded by the constructed candidate has database support at most min(q,N); its next actual coherent query has support at most min(q+1,N). `Fin N` is a zero-based encoding of the manuscript's `[N]`; **N is the permutation
domain size**, not the bit-string width. The latter is `w`, with an injective
encoding `Fin N ↪ (Fin w → Bool)`.
